# Student Management System - Frontend Web Application

Modern React 18 + Vite frontend for the Student Management System.

## Tech Stack
- **React 18**
- **Vite 5**
- **Tailwind CSS 3**
- **React Router DOM 6**
- **Axios**
- **Recharts 2**
- **Lucide React Icons**

## Features
- Role-based protected routes (Admin, Teacher, Student)
- Role-aware dynamic dashboards with interactive Recharts
- Student & Faculty directories with search, filter, and pagination
- Course catalog & Enrollment management
- Bulk attendance tracker with single-click marking
- Grade recording with real-time GPA and letter calculation
- CSV export for student lists and transcripts
- Responsive layout with dark mode toggle

## Getting Started

### Prerequisites
- Node.js 18+ & npm

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Access the application at [http://localhost:5173](http://localhost:5173).

### Build for Production
```bash
npm run build
```
The optimized bundle will be in `/dist`.
